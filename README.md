# p8-react

Лабораторная работа № 1. Каталог из пяти товаров на React и Vite.

Кнопка `+` увеличивает количество у выбранного товара. У каждой карточки свой счётчик.

## Запуск

В папке проекта выполните:

```powershell
npm.cmd ci
npm.cmd run dev -- --host 127.0.0.1
```

Откройте адрес из строки `Local` в терминале. По умолчанию это [http://127.0.0.1:5173/](http://127.0.0.1:5173/).
Фотографии загружаются с Unsplash.

## Проверка

```powershell
npm.cmd run lint
npm.cmd run build
```
